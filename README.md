# Sample 1: Spartan AI (1:1 Transpiled Showcase)

High-performance neural architecture landing page transpiled 1:1 from Framer with zero AI slop, native harmonic linear() spring physics, 60fps infinite marquee ribbons, interactive click/toggle variant state machines, and integrated Vercel Web Analytics.

## ✨ Architecture & Motion Highlights

- **Linear() Harmonic Oscillator Springs**: Synthesized parent-to-child cascading hover states with mathematical spring curves directly in CSS.
- **60fps Infinite Marquee / Ticker Engine**: Zero-jank continuous ticker loops across trust logos, capabilities, and testimonial ribbons.
- **Interactive State Machines**:
  - **FAQ Accordions**: Expand and collapse with smooth View Transitions API morphing.
  - **Dynamic Pricing Toggle**: Seamless monthly/annually switch with animated knob displacement and price recalculation.
  - **3D Perspective Tilt**: Gyro and cursor tracking on cards with automatic spring back.
- **Analytics**: Pre-configured with Vercel Web Analytics (`/_vercel/insights/script.js`).

## 🛠️ Stack

- Native Semantic HTML5
- GPU-Accelerated CSS3 with CSS variables & `linear()` timing curves
- Zero-Dependency Vanilla ES6 JavaScript Bridge
- Vercel Edge Hosting
